# Atech Pool Service — Website

A modern, responsive redesign for **Atech Pool Service** — pool cleaning, repair,
maintenance and remodeling.

## Stack

Vanilla HTML, CSS and JavaScript. No build step and no dependencies — open
`index.html` in a browser or serve the directory statically.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Single-page site: hero, services, why-us, credentials, gallery, appointment form, contact |
| `styles.css` | All styling, custom properties and responsive breakpoints |
| `script.js` | Mobile nav, sticky header, scroll reveals, gallery lightbox, form validation |
| `privacy-policy.html` | Privacy Policy |
| `terms.html` | Terms |
